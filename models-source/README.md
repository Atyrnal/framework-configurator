# Source CAD

`framework-laptop-13-pro.stp` is Framework Computer Inc.'s official Laptop 13 Pro CAD assembly. The browser version is exported to `public/models/framework-laptop-13-pro.glb` by `scripts/export-framework-pro.FCMacro` using FreeCAD.

Source: [FrameworkComputer/Framework-Laptop-13](https://github.com/FrameworkComputer/Framework-Laptop-13), file `Framework Laptop 13 Pro CAD.stp`.
