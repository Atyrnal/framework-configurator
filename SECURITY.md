# Security policy

## Reporting a vulnerability

Please report security issues privately through [GitHub Security Advisories](https://github.com/durguto/framework-configurator/security/advisories/new).

Do not open a public issue, and do not post proof-of-concept details in a pull request, until the report has been acknowledged.

## Scope

This repository is a static configurator. It has no accounts and no server-side secrets. Reports that matter are things like cross-site scripting in the viewer, unsafe handling of shared URLs, or a dependency with a known vulnerability that affects the deployed site.

## Supported versions

Only the `main` branch is supported.
