# Contributing

Thanks for helping improve the configurator.

## Setup

Node.js 22 or newer.

```bash
npm install
npm run dev
```

`npm run dev` serves the app at http://localhost:5173.

Before opening a pull request:

```bash
npm run lint
npm run build
```

## What to send

- One change per pull request, with a short explanation of why it is needed.
- UI changes need a note about what you clicked through.
- Do not commit secrets, `.env` files, or Cloudflare credentials.
- Do not relicense the Framework CAD. Those files stay under CC BY 4.0. See NOTICE.

## Reporting issues

Use the bug or feature templates. Security reports go through [GitHub Security Advisories](https://github.com/durguto/framework-configurator/security/advisories/new), not a public issue.
